# EarningCall

Project workspace for earnings call keyword extraction, topic modeling, and dynamic capability analysis.

## Structure

- `data/` - source earnings call data and reference documents
- `scripts/` - reusable Python scripts for extraction and analysis
- `results/` - generated tables, figures, and analysis outputs
- `notebooks/` - exploratory and modeling notebooks

## Typical Workflow

1. Put source files in `data/`.
2. Run analysis scripts from `scripts/`.
3. Save generated tables and figures in `results/`.
4. Keep exploratory notebook work in `notebooks/`.
